# Personal Shape Website – Redesign Project

This project is a **redesign of the “Personal Shape” website**, created as a **practice exercise from Dugsiiye**.  
The main goal of this project is to **learn how to build a website collaboratively using GitHub** while improving frontend development skills.

---

## 📌 Project Overview

- Website Type: Personal / Portfolio Website
- Project Nature: Redesign (UI & structure improvements)
- Purpose: Learning & practice
- Platform: GitHub collaboration
- Teamwork: Built with friends using GitHub collaboration features

---

## 🎯 Objectives

- Practice **HTML & CSS** fundamentals
- Improve **responsive web design**
- Learn **GitHub collaboration** (clone, branch, commit, push, pull)
- Work as a team on the same project
- Understand real-world frontend workflow

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Google Fonts  
- GitHub (Version Control & Collaboration)

---

## 🤝 Collaboration Workflow

This project was built using GitHub collaboration:

1. Repository created on GitHub
2. Collaborators invited
3. Each member:
   - Cloned the repository
   - Worked on specific sections
   - Committed changes
   - Pushed updates to GitHub
4. Changes were reviewed and merged

This helped us understand **team-based development**.
